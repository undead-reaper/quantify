# Quantify

A modern, intuitive unit conversion app that makes converting between different units effortless. Built with performance and user experience in mind.

[![Live Demo](https://img.shields.io/badge/Live-Demo-blue?style=for-the-badge)](https://quantify-ten.vercel.app)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg?style=for-the-badge)](https://www.gnu.org/licenses/gpl-3.0)
[![Built with Vite](https://img.shields.io/badge/Built%20with-Vite-646CFF?style=for-the-badge&logo=vite)](https://vitejs.dev)

## ✨ Features

- **8 Conversion Categories**: Length, Mass, Temperature, Volume, Area, Speed, Time, and Data
- **Clean & Modern UI**: Sleek interface built with shadcn/ui components
- **Dark & Light Mode**: Seamless theme switching for comfortable use
- **Responsive Design**: Perfect experience across desktop, tablet, and mobile
- **Real-time Conversion**: Instant results as you type
- **Copy Results**: One-click copying of conversion results
- **Bidirectional Conversion**: Easy swap between "From" and "To" units

## 🏃‍♂️ Quick Start

### Prerequisites

- [Bun](https://bun.sh) installed on your machine

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/undead-reaper/quantify.git
   cd quantify
   ```

2. **Install dependencies**
   ```bash
   bun install
   ```

3. **Start the development server**
   ```bash
   bun --bun run dev
   ```

4. **Open your browser**
   ```
   http://localhost:5173
   ```

## 🎯 Supported Conversions

### 📏 Length
Millimeter, Centimeter, Meter, Kilometer, Inch, Foot, Yard, Mile

### ⚖️ Mass
Milligram, Gram, Kilogram, Ounce, Pound, Stone, Ton

### 🌡️ Temperature
Celsius, Fahrenheit, Kelvin

### 🥤 Volume
Millilitre, Centilitre, Litre, Cubic Litre, Fluid Ounce, Cup, Pint, Gallon

### 📐 Area
Square Millimeter, Square Centimeter, Square Meter, Hectare, Square Kilometer, Square Inch, Square Foot, Square Mile, Acre

### 🏃‍♂️ Speed
Meters per Second, Kilometers per Hour, Miles per Hour, Knots, Foot per Second

### ⏰ Time
Millisecond, Second, Minute, Hour, Day, Week, Month, Year

### 💾 Data
Bit, Byte, Kilobyte, Megabyte, Gigabyte, Terabyte
